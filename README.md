# 🚀 Modern Full-Stack E-Commerce Web Application

A modern, responsive e-commerce web application featuring a sleek **Glassmorphism** dark UI design, built for an optimal user experience and seamless performance.

## ✨ Features
- **Modern UI/UX:** Designed with Tailwind CSS utilizing a gorgeous dark glassmorphism theme.
- **Responsive Layout:** Fully adaptive across desktop, tablet, and mobile devices.
- **Interactive Pages:** Includes Home/Index, About Us, Contact, Privacy Policy, and Terms of Service.
- **Dynamic Elements:** Product catalogs, shopping bag drawer, and smooth navigation.

## 🛠️ Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla JS)
- **Backend:** Node.js, Express.js
- **Database:** Oracle Database 21c XE

## 📂 Project Structure
- `index.html` - Main landing page & product catalog
- `about.html` - Company / project background information
- `contact.html` - Customer support and inquiry page
- `privacy.html` - Privacy policy guidelines
- `terms.html` - Terms of service agreements
- `script.js` - Interactive frontend logic & cart state management
- `server.js` - Express backend server routing
